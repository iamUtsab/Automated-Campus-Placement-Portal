# Campus Placement Portal 🎓

Full-stack web application for automated campus placement management, job eligibility screening, and email notifications.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (located in `public/`)
- **Backend:** Node.js, Express.js (`server.js`)
- **Database:** MongoDB / Mongoose (`models/`)
- **Authentication:** JWT & Bcrypt

## Setup
1. `npm install`
2. Configure `.env` based on `.env.example`
3. `npm start`
